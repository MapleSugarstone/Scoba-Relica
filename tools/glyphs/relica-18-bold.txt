; Glyphs drawn by hand for the bold 18 px face. Each one replaces what the
; sampler made of that character, and the build leaves it exactly as drawn.
;
; A glyph starts with `glyph`, the character, and the row its bottom row sits
; on, counted up from the baseline: 0 for a letter resting on the line, below
; zero for a descender. Its rows follow top to bottom, # for ink and . for
; none. Blank columns either side are trimmed, so only the ink sets the width.

; The sampler's A had a left stroke that alternated three and four pixels wide
; against a right stroke of four. Both strokes here are five, the width of the
; H and N stems, stepping one column every two or three rows so each reads as
; a straight line. Same box as before, so the spacing around it is unchanged.
